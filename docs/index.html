Make a model change reviewable.

Use your own aligned instance maps to turn an upgrade, a threshold change, or a manual edit into a concrete review.

01

Find the affected regions

Inspect merges, splits, disappearances, and pixels entering or leaving excluded space. Instance IDs can differ between runs.

02

Open a local visual report

Generate a self-contained HTML report from your label maps. Keep your drawings and derived reports in your own workspace.

03

Request review in a pipeline

Add --fail-on merge disappeared to write the report and exit 1 when a selected change occurs. The gate requests inspection, not a verdict on accuracy.

Bring your two label maps.

Install PlanRegions v0.3.0 in your Python environment, then compare two runs. Python 3.10 or newer is required. Releases are on GitHub; no PyPI package is currently published.

Install the tagged source
python -m pip install "git+https://github.com/crown-sports/planregions.git@v0.3.0"
Write JSON and a local HTML report
planregions compare --before runs/before/labels.npz \
  --after runs/after/labels.npz --output runs/review/changes.json \
  --html-output runs/review/changes.html

Both maps must use the same original pixel grid. Equal image dimensions alone do not establish alignment. Use integer labels, not color previews.

Every positive pixel overlap contributes to the correspondence. Small boundary shifts can join a group; examine the pixel counts. Changes alone do not tell you which result is correct.

Two tools. Clear handoffs.

Start from the output you already have. Each package works independently, and their documented mask contract connects them.

WallGraph · v0.1.2

Wall predictions → connection graphs

Connect an existing wall model and carry its predictions into original-coordinate polylines, junctions, and loops. Model adapters and geometry stages are replaceable.

Explore WallGraph
PlanRegions · v0.3.0

Wall masks → regions you can inspect

Keep polygon holes, exact pixel areas, and explicit region merges. Compare two outputs in a visual report, with no neural model required for geometry.

Explore PlanRegions

Both projects are experimental. No real datasets or pretrained weights are distributed. WallGraph requires your own compatible model for real drawings; region changes do not establish semantic correctness.
