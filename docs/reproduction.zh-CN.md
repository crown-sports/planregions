# 区域识别实跑中学到的几件事

[English](reproduction.md) · [方法与论文](methods.zh-CN.md) · [完整验证](validation.md)

区域提取的困难常常从一条不完整的墙开始：一个小缺口能让两个房间相连，也能让室内连到图像外部。实跑经验因此围绕屏障、划分和实例评估展开。以下来自真实配对实验及验证驱动修复，描述经典方法在图纸上的工程复现。

## 把上游影响和区域几何分开

只有端到端结果，很难知道错误来自墙体还是区域。我们保留同一旧墙体输入的对照，再评估新墙体加新区域；真值墙体只用于辅助诊断。官方 SVG 标注来自 [CubiCasa5K](https://arxiv.org/abs/1904.01920)，30 张测试有 322 个区域实例，配置先在 15 张验证图上冻结。

相同旧墙体下，新连通域 macro PQ 为 0.69868，旧区域 API 为 0.68034；差值 95% 区间为 [−0.69, +4.35] 个百分点。新两阶段 PQ 为 0.56580，区间显示退步。这使问题更具体：同输入的几何尚未证明稳定改善，上游缺墙也会放大为漏分和合并。

## 外部排除的时机很重要

先分水岭、再删除触边实例，会让原本连接到图外的自由空间被切出不触边的碎块，看起来像室内。修复把外部连通域排除移到划分之前，构造反例进入回归测试。

规则更一致，却仍依赖输入证据。真实外墙有开口时，整个内部可能被排除。此时应提供明确的建筑范围或分隔线；默认自动补墙会改变真实门洞，因此保持关闭。

## 一个平坦平台不应反复播种

长方形房间的距离图可能有一条平坦脊线。仅按间距选峰，会把它当成多个房间种子。修复先把局部极大值平台连成一个集合，再选集合内真实像素作为代表；没有种子的自由连通域也获得一个种子。

构造长房间通过了检查，但真实预测墙体仍会产生多峰。测试上分水岭输出 1,273 个实例，真值只有 322，macro PQ 0.29763；连通域为 0.56580。修复成立与策略适合真实输入，需要分别验证。分水岭继续保留为可选项。

## 几何的依据留在像素里

用标签图计算面积，孔洞、障碍物和排除像素可以继续核对。多边形用于几何表达，简化后的面积可能不同；质心可能落在孔洞里，所以另外输出区域内点。合并之后重新生成几何，墙体与孔洞保留，语义冲突归为未知。

这部分由 20 项区域测试、生成布局和 JSON/NPZ 往返检查支持。45 张验证／测试图的属性注入没有改动实例标签。业务属性没有人工真值，故只记录接口和几何不变量，不给出语义准确率。

## 对齐指标，再解释速度

区域编号应当不影响成绩。实现先紧凑编号，再统计包含背景的交叉像素；实际一对一求解器为 SciPy 的 Jonker–Volgenant 变体。PQ 借鉴 [Panoptic Segmentation](https://arxiv.org/abs/1801.00868)，本项目的无类别、阈值包含等号等规则明确记录，不能直接当作原论文榜单协议。

一个 512×512、64 实例构造布局中，新旧计数实现各指标相同，单次耗时为 392.26/8.06 ms。它用于核对优化与结果一致性，没有重复性能实验，不能推出生产提速比。

## 后续复用

先固定墙体极性、坐标、实例真值和开放区域的定义。默认连通域先作为基线，再分别验证 footprint、separator 或分水岭。相同墙体对照帮助定位几何变化，端到端测试检查最终用途。新一轮调参应使用新保留集。

公开代码和命令可在使用者自己的授权输入上复用。冻结名单、参考模型与逐图输出保持私有，公共下载包不能重建本次完整配对成绩表。公开素材仍只有 WallGraph 的一张简单生成图，PlanRegions 的 demo 在内存中生成。
