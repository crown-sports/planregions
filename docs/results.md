# 实测记录（更新于 2026-10-04）

当前结论：相同旧墙体掩码下，新区域几何 PQ 点估计略高，统计区间跨零；新墙体加新区域的整体 PQ 下降。可选分水岭在预测墙体上明显过分割，默认继续使用连通域。本项目作为实验几何工具库公开发布；当前不满足作为整体质量不降低的系统替代的条件。

## 数据与评测范围

使用 [CubiCasa5k](https://github.com/CubiCasa/CubiCasa5k) 官方 SVG 人工标注及 train/val/test，推理前冻结 seed 20261003 的均衡选择：15 张验证、30 张测试，三个来源的测试图各 10 张；原图组及完全相同的图像字节跨 split 不重复。图片、标注、名单和逐图输出保留私有，不进入发布包。数据来自 [官方 Zenodo](https://zenodo.org/records/2613548)，采用 CC BY-NC 4.0；既有模型训练暴露未知，无法排除曾见过官方测试图。

区域真值逐个 rasterize SVG `Space`，排除 Outdoor、Background 并清除结构 Wall 像素，测试集合计 322 个实例。结构 Wall 标签 2 含门窗开口结构，与完全闭合屏障有区别。房间类型也与业务属性 `un_place` 不同，所以只测区域实例几何，不报告语义准确率。

原图尺寸下使用 SciPy 的一对一线性指派（改进 Jonker–Volgenant），先最大化 `IoU >= 0.5` 的匹配数，再最大化所有指派对的总 IoU；指标只计入达标配对。实例 `F1 = TP/(TP+0.5FP+0.5FN)`；`PQ = 达标配对IoU之和/(TP+0.5FP+0.5FN)`。macro 每图等权，micro 汇总实例。协议包含等号且不要求类别一致，不能直接与严格大于 0.5 或带语义的评测榜比较。

新墙体阈值 0.5、闭运算半径 2 仅由验证集选定。区域修复后，15 张验证图端到端 macro PQ 为连通域 0.61747、分水岭 0.36000，测试前冻结连通域。区域阶段最小面积 64、不补墙、不提供真值范围或门窗分隔线；分水岭对照固定峰间距 20，未用测试调参。

## 30 张测试图结果

全部完成，0 个解析／识别失败。旧完整区域流程保留属性模型及其几何修正；新默认属性未知。另测相同旧墙体输入，区分上游墙体与区域几何的影响。

| 输入与区域方法 | macro PQ | macro 实例 F1 | micro PQ | 预测实例数 |
| --- | ---: | ---: | ---: | ---: |
| 旧墙体 + 旧完整区域流程 | 0.68034 | 0.75300 | 0.69466 | 330 |
| 同一旧墙体 + 新连通域 | 0.69868 | 0.75786 | 0.72019 | 296 |
| 新选定墙体 + 新连通域，端到端 | 0.56580 | 0.61474 | 0.55180 | 181 |
| 新选定墙体 + 新分水岭，对照 | 0.29763 | 0.36960 | 0.22636 | 1273 |
| 真值墙体 + 新连通域，输入辅助诊断 | 0.79272 | 0.83008 | 0.82173 | 259 |
| 真值墙体 + 新分水岭，输入辅助诊断 | 0.79583 | 0.83897 | 0.79025 | 387 |

真值墙体行依赖人工信息，不能当成全自动效果。即便有真值墙体也没有达到 PQ 1，开放区域、标注定义和几何策略仍有影响。

逐图配对、三个来源内 bootstrap 10,000 次，seed 20261003，百分位 95% 区间。相同旧墙体的新几何相对旧完整流程的平均 PQ 差为 **+1.83 个百分点，[−0.69, +4.35]**，24 张提升、6 张下降；区间跨零，不证明稳定提升或满足非劣效条件。新完整两阶段流程相对旧完整流程为 **−11.45 个百分点，[−20.25, −3.40]**，15 张提升、15 张下降。

新墙体像素 IoU 比旧最终输出高 5.72 个百分点，但平均召回率由 0.95247 降至 0.88687。新端到端 TP/FP/FN 为 151/30/171，旧完整为 250/80/72。新流程漏分／合并更严重；缺口可能连接多个房间，也可能把内部与外部连通后排除。私有失败案例支持此解释，尚未对所有错误做完整人工原因标注。

## 0.1.1 的验证驱动修复

在实例划分之前排除触边自由空间，防止分水岭制造伪室内；同一距离极大值平台只放一个实际像素种子，修复长方形房间重复播种；评估改为一次交叉计数，保持原匹配定义并支持稀疏大整数实例 ID。第三方策略的 unsigned／稀疏 ID 安全归一化，不按 ID 数值分配数组。

修复依据为验证错误和构造反例，之后运行本轮测试。平台修复仍不能消除噪声墙体的多峰过分割，因此分水岭保留为可选策略。

20 项区域测试通过，联合墙体共 33 项本地通过；服务器共 32 项通过、1 项墙体 CPU-only 检查跳过。100 个生成布局通过几何／协议不变量检查，5 个布局做 JSON/NPZ 往返；生成检查不代表识别准确率。全部 45 张验证／测试图的属性注入未改变实例标签，但业务属性没有真值，不能报告语义精度。

共同质量环境为 Linux、Python 3.12.14、NumPy 1.26.4、OpenCV 4.11.0.86、SciPy 1.14.1、scikit-image 0.24.0、ORT GPU 1.26.0；区域与属性均使用 CPU。质量实验的单次耗时不作为生产性能结论。仍需门洞／范围预测、数值一致性、业务标注和新的保留测试集，才能在后续修复后重新判断整体替代质量。

## 先期记录（2026-10-03，以下描述当时状态）

在同一授权服务器上使用 4 张真实测试图，通过 WallGraph 的外部 ONNX 模型适配器生成原图坐标的墙体掩码，再送入本工程。墙体掩码是预测结果，不是人工真值。区域实例与语义人工标注未提供，因此以下数字只能说明链路和性能。

每张预热 1 次、测量 3 次，共 12 次。计时排除墙体识别、文件 I/O、模型创建与预热；默认连通域、关闭补墙和分水岭，最小区域面积 64 像素。原始输入尺寸（H×W）为 404×450、479×600、500×444、933×1400。

| 范围（服务器 CPU 执行） | 中位耗时 | P95 |
| --- | ---: | ---: |
| 区域划分、几何与邻近图，属性未知 | 41.76 ms | 232.51 ms |
| 同流程加外部 ONNX 属性模型 | 741.66 ms | 1383.22 ms |

区域几何随图片尺寸和区域数量变化，P95 明显高于中位数；12 次测量不足以说明生产尾延迟。不能把这两行与墙体 GPU 时间简单相加来报告端到端 P95。4 张图得到的区域数范围为 6–11，但数量和边界未经人工核对。

区域几何在优化时将每个实例的轮廓与距离变换限制到其包围盒，随后恢复原图坐标，避免对每个实例反复计算整幅距离图。孔洞、内点和坐标回归测试均通过。没有进行旧工程对照实验，因此不报告新旧性能提升比。

属性模型输入 1×3×512×512，使用原有模型接口对应的 BGR 通道、直接缩放和最近邻预处理。只映射源码中已明确的类别 2 为 `un_place`，其他类别保持未知；区域多数占比阈值 0.6。模型 SHA-256：`e56cd8cc220acd391cb36277d9a58e60ba329c9756be903a51e7a0ce3d39425a`。该流程没有复刻旧系统的 OCR 补充和属性几何修正，也没有验证这些属性的准确率。

环境为 Linux x86_64、Python 3.12.14、NumPy 2.5.3、OpenCV 5.0.0.93、ONNX Runtime 1.26.0；属性使用 CPUExecutionProvider，4 个推理线程。服务器配有 RTX 5090，但此处区域流程没有使用 GPU。

本地 15 项测试通过：区域和孔洞、建筑范围、显式分隔线、分水岭覆盖、类别映射与未知属性、邻近关系、合并与导出恢复、合并后的属性覆盖率、实例编号无关评估、输入契约、RGB/BGR 模型适配与发布边界。墙体简单图联用得到 3 个区域。

下一步需要独立人工实例标注和语义标注，分别验证实例 F1/PQ、区域数误差、孔洞保留、开口导致的泄漏和属性准确率。当前不宣称达到生产级精度，也不宣称新的基础算法。
